# L3 outreach email (§4, send after Phase 1)

Fill in the brackets before sending. Send it from a team member's university email, CC the course faculty, and attach nothing: the link is enough. L3 needs **written confirmation** plus 2+ weeks of real usage, so the reply itself is evidence. File it in the submission folder.

---

**To:** [Name], [Placement cell / Department of ___]
**CC:** [Course faculty]
**Subject:** Pilot request — placement prep platform (student project)

Hello [Name],

We're Group 8 (INT252/257): Deepanshu Lathar, Harsh and Sundram Singh. We're building "Beyond the Rumour Mill", a platform where verified senior interview experiences feed personalised prep plans for juniors. It replaces placement rumours with attributable data.

It is live at **https://beyond-the-rumour-mill.vercel.app**. Today it does the following:

- Students see which drives they are eligible for, with the exact reason when they are not.
- Plans are generated from verified senior experiences, weighted by how often and how recently each topic was asked.
- A rumour check answers claims like "TCS only asks DP" against the verified data, citing every experience it used.
- Placement-cell admins verify each senior submission against evidence (offer letter or interview email). Evidence is private and viewable only through a 60-second link.

We'd like to pilot it with [department/cell]. On your side, the pilot would be:

1. List one real upcoming drive (we can enter it from your notice).
2. Verify a few senior experiences in the admin queue (about 2 minutes each).

We'd handle everything else: onboarding juniors, collecting senior experiences, support. After two weeks we'd share a usage report covering accounts, submissions, plans generated and checklist progress.

Would a 15-minute walkthrough next week work? [Two proposed slots]

Thank you,
[Name], on behalf of Group 8
[Phone] · [University email]

## After a yes

- Create their admin account. They sign up at `/login`, then a team member promotes them with the README "admin promotion" SQL, which uses the service role. There is no UI for this, by design.
- Record the pilot start date. Usage evidence covers accounts, submissions, plans and checklist ticks; export it from Supabase at the end of week 2.
- Ask for the written confirmation (email or letter) to state that the department **used** the platform, over which dates, and for which drive.
