# The bar: pudding.cool (homepage, captured 2026-11-03)

The Pudding publishes visual essays that explain ideas with data. It is the bar for our homepage because it is the opposite of a template: the page is a catalogue of the actual content, not a pitch about it. Five mechanisms, each checkable from screenshots:

1. **The content is the hero.** The first viewport shows the catalogue itself (three numbered entries), not a headline + subhead + two buttons + feature cards.
2. **Every entry is numbered and filed.** A mono index pill (`#226`) on the left and a mono stamp (`OCT 2026`) on the right sit above each entry, like a register.
3. **Each entry has a flat mat holding a real artefact.** A solid, square-cornered colour block frames a crop of the actual chart. No gradients, glows, shadows or icons.
4. **Plain, confident type hierarchy.** One heavy display title per entry, then one line of plain description. No uppercase eyebrow above every block, no "How it works".
5. **One handmade tell.** Sticker-style logo and nav marks give the page a human hand. Everything else is quiet.

## How ours maps (and stays ours)

Dark ground, amber the only accent (`design-system.md`). Entries are **hostel rumours**, numbered `#01…`, each on a paper mat, with the live verdict from `checkClaimVerdict()` stamped on it. The stamp is our handmade tell. Copying Pudding's colours, wording or stickers loses automatically.

The craft critic compares ours (desktop 1440 at 0 / 900 px scroll, mobile 390) to `ref-pudding-*.png`, labels stripped: PASS only if ours reads as a crafted publication, not a generated template.
